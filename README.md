# fbl-daten

Daten für einen privaten, kostenlosen Newsticker zur Frauen-Bundesliga.

- `news.json`: Meldungen mit Quellenangaben
- `spielplan.json`: Spieltage, Ergebnisse, Aufstellungen
- `patchnotes.json`: Änderungen pro Update
- `fotos/`: Spielerinnenfotos, Lizenz und Urheber je Bild in `fotos.json`
- `logos/`: Vereinslogos, Nutzung mit Freigabe der Vereine
